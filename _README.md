# Odin Recipes

This project follows The Odin Project's curriculum in order to create a simple recipes web page while demonstrating an understanding of HTML and CSS. 

---

**Page Details**
- HTML
    - Coded a home page for the recipes project
    - Coded 3 recipe pages using an HTML boilerplate template to start
- CSS
    - Added styling to home page to enhance design
    - Added styling to the individual recipe pages for enhanced design

---

## Lessons Learned

- Syntax is important! Spell your code correctly! Or Silly things can happen!
- Its worth it to get familiar with developer tools in your browser. Often times it helps highlight what the actual conflict is versus "trial-and-error" approaches
- Design choices are important. You should always write your code in such a way that it is accessable across all medium, and especially to this who may have trouble viewing your content
